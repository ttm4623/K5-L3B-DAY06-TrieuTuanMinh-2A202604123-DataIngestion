DAY 06 - KET QUA DANH GIA RETRIEVAL
===================================
Trang thai: PIPELINE HOAN TAT (theo output terminal nguoi dung cung cap)

Nguon so lieu:
- Cac metric va so chunk duoi day duoc chuyen tu output terminal do nguoi dung
  cung cap; khong tu chay lai pipeline.
- Output benchmark khong ghi trace tung cau hoi; mot output similarity-search
  rieng co Chunk ID va score, duoc ghi o muc 4.
- Khong co nhan cham thu cong coherence, metadata hay grounding.

1. CAU HINH VA SO CHUNK
-----------------------
- Embedding: all-MiniLM-L6-v2, 384 dimensions.
- Strategy A (fixed): 2,150 chunks; size=500, overlap=50.
- Strategy B (paragraph): 1,210 chunks; max_size=800.
- Strategy C (paragraph + filter): 1,210 chunks; max_size=800.
- Vector store: PostgreSQL + pgvector; cosine search theo source code.

2. HIT RATE
-----------
Strategy A:
  Dev  (15 cau): Hit@1 1/15 = 6.67%; Hit@3 2/15 = 13.33%.
  Test  (5 cau): Hit@1 2/5  = 40.00%; Hit@3 2/5 = 40.00%.
Strategy B:
  Dev  (15 cau): Hit@1 1/15 = 6.67%; Hit@3 2/15 = 13.33%.
  Test  (5 cau): Hit@1 1/5  = 20.00%; Hit@3 1/5 = 20.00%.
Strategy C:
  Dev  (15 cau): Hit@1 1/15 = 6.67%; Hit@3 2/15 = 13.33%.
  Test  (5 cau): Hit@1 1/5  = 20.00%; Hit@3 1/5 = 20.00%.

Tong hop ca 20 cau (tinh tu so dem tren):
  A: Hit@1 3/20 = 15.00%; Hit@3 4/20 = 20.00%.
  B: Hit@1 2/20 = 10.00%; Hit@3 3/20 = 15.00%.
  C: Hit@1 2/20 = 10.00%; Hit@3 3/20 = 15.00%.

Hit@3 la ten metric terminal in ra. Ma nguon kiem tra evidence quote trong
chunk; can luu trace de kiem tra tung hit va cach match evidence.

3. NHAN XET / GIOI HAN
---------------------
- Tren tap test 5 cau nay, A cao hon B va C 1/5 cau o ca Hit@1 va Hit@3.
- Dev cua ca ba strategy bang nhau theo output.
- B va C co cung so chunks va cung metric trong output; chua thay loi ich
  dinh luong cua filter tren benchmark nay.
- Mau test chi co 5 cau; khong suy rong ket qua thanh ket luan tong quat.
- Benchmark hien tai khong co truong filter; source C ap dung section=
  "chapters" co dinh cho moi truy van, nen chua danh gia duoc filter theo
  yeu cau tung cau.
- So chunk khop tong 4,570 dong da quan sat truoc do (2,150 + 1,210 + 1,210).
- Parser da duoc kiem tra rieng truoc do chi tra ve 1 unit voi page_id rong
  trong khi manifest liet ke 43 units; can doi chieu mapping truoc khi tin
  rang moi chunk co truy vet nguon/unit chinh xac.
- Khong co Chunk ID/score gan voi tung cau benchmark trong output benchmark.
- Thoi gian, chi phi, coherence, metadata audit va grounding thu cong:
  chua co so lieu.

4. KET LUAN
-----------
Theo metric terminal, A co ket qua test cao hon mot cau so voi B/C, con B/C
bang nhau. Day la ket qua tren bo test nho, chua du bang chung de khang dinh
A tot hon noi chung. Can bo sung trace top-3 (question ID, Chunk ID, score,
metadata, text va gold), xac minh page/unit mapping, va cham thu cong cac
tieu chi con thieu truoc khi hoan tat bao cao.

5. KET QUA SIMILARITY SEARCH RIENG
----------------------------------
Output terminal co mot truy van similarity search kiem thu, tach rieng voi
bang Hit@1/Hit@3 benchmark. Theo source run_pipeline.py, truy van kiem thu la:
"What did Tesla invent regarding alternating current motors?"

Top 1: Chunk ID _fixed_020 | similarity 0.7939
Top 2: Chunk ID _fixed_217 | similarity 0.7654
Top 3: Chunk ID _fixed_019 | similarity 0.7237

Output cho biet chunk ID chi co suffix "_fixed_..." (khong co page/unit ID).
Khong dung ba score nay lam metric Hit@3 benchmark; can giu ro day la mot query
kiem thu rieng.
